# Практическая работа № 8 — Модели каталога и источник данных

## Результат
MVC-магазин использует модели Product и Category и JsonProductRepository. Каталог загружается из JSON, фильтруется по категории и сортируется. Есть отдельная карточка товара.

## Запуск
PHP 8.0+: `php -S localhost:8000 -t public`, затем http://localhost:8000.

## Маршруты
- `/` — главная;
- `/catalog` — каталог, фильтры `?category=ID` и сортировка `?sort=price_asc|name`;
- `/product?id=ID` — карточка товара, неизвестный id даёт 404.

## Проверка
Сверьте каталог с products.json и categories.json. Проверьте фильтр каждой категории, сортировку и неизвестный id. catalog_cases.csv содержит контрольные сценарии.

## Ограничения
Источник данных — JSON-файлы. Корзина и оформление заказа добавляются в следующих работах.
